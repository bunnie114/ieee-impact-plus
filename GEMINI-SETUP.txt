IEEE Impact++ — Gemini setup

The backend AI provider has been switched from OpenAI to Google's Gemini API.

1. In backend, activate your existing virtual environment.
2. Install/update dependencies: pip install -r requirements.txt
3. Copy backend/.env.example to backend/.env (or edit your existing backend/.env).
4. Set GEMINI_API_KEY to your key from https://aistudio.google.com/app/apikey
5. Keep GEMINI_MODEL=gemini-3.8-flash unless you choose another model available to your API key.
6. Restart the backend: uvicorn app.main:app --reload

Do not commit .env or expose the API key in frontend code.
The frontend and database configuration are unchanged.
